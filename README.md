# TG Bot Agent Starter Kit

Пакет для запуска нового Telegram-бота-агента на базе рабочей версии `tg-kd-agent-bot`.

Внутри уже есть:
- чтение сообщений в личке и разрешённых группах;
- guard по `user_id` и `chat_id`;
- журнал поручений, вопросов, решений, рисков и заметок;
- разбор длинных сообщений и голосовых в сущности;
- сводки по чатам;
- утренние, дневные, недельные и пользовательские сводки;
- запросы к управленческому дашборду;
- проверка свежести источников;
- ClickUp-задачи с фильтрацией по ответственным;
- ответы на русском и узбекском;
- отправка сообщений в выбранные группы;
- регулярные напоминания и запросы статуса;
- генерация оформленного сообщения для команды по короткому набору доступов.

## Быстрый запуск

1. Создать нового Telegram-бота через BotFather и получить токен.
2. Скопировать `.env.example` в `.env`.
3. Заполнить `TG_DASHBOARD_BOT_TOKEN`, `TG_AGENT_ALLOWED_USER_IDS`, `TG_AGENT_ALLOWED_CHAT_IDS`.
4. Запустить самопроверку:

```bash
python3 scripts/tg_bot_agent.py --config data/tg_bot_agent.config.example.json self-test
```

5. Запустить один цикл:

```bash
set -a; source .env; set +a
python3 scripts/tg_bot_agent.py --config data/tg_bot_agent.config.example.json once
```

6. Если всё нормально, запускать постоянно:

```bash
python3 scripts/tg_bot_agent.py --config data/tg_bot_agent.config.example.json run
```

## Важно про секреты

В репозиторий нельзя класть `.env`, токены Telegram, ClickUp, пароли, реальные выгрузки, историю чатов и клиентские данные. Для передачи живого бота секреты передаются отдельно: через парольный менеджер, защищённый архив или закрытый серверный контур.

## Где что лежит

- `scripts/tg_bot_agent.py` — основной Telegram-агент.
- `scripts/build_bot_digests.py` — сборщик сводок и текстов по дашборду.
- `data/tg_bot_agent.config.example.json` — настройки рантайма.
- `data/bot_alert_config.example.json` — расписания и шаблоны сводок.
- `.env.example` — список переменных для подключения.
- `docs/` — инструкции для эксплуатанта и разработчика.
- `ops/` — пример фонового запуска на macOS через launchd.

## Проверка перед передачей

Перед отдачей новому владельцу:
- заполнить `.env` локально;
- отправить боту `/whoami` от каждого пользователя и добавить их ID в guard;
- добавить бота в нужные группы и добавить `chat_id` групп;
- проверить `/health`, `/doctor`, `/self_test`;
- спросить в Telegram: `что умеешь`, `задачи по мне`, `сводка за день`, `какая выручка за вчера`;
- проверить, что бот предупреждает о старых данных.

Для передачи Claude / новому разработчику сначала открыть:

```text
docs/HANDOFF_CLAUDE.md
```
