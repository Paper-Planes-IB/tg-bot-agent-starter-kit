# Gate-аудит бота

Дата проверки: 2026-08-30

## Закрыто в коде

### G1. Ложный красный статус doctor

Симптом: `doctor` мог показывать `FAIL digest config`, если проверку запускали не из runtime-папки.

Причина: относительный путь `data/...` читался относительно текущей папки терминала.

Решение: относительные runtime-пути теперь разрешаются относительно папки бота.

Проверка:

```bash
python3 scripts/tg_bot_agent.py --config data/tg_bot_agent.config.example.json self-test
```

### G1. Потеря Telegram Business-сообщений

Симптом: Telegram Business-сообщения прилетали, но попадали в `business_message_ignored`.

Причина: если бот пропустил событие `business_connection`, он не знал владельца подключения и отбрасывал сообщения.

Решение: добавлен явный allowlist:

```bash
TG_AGENT_ALLOWED_BUSINESS_CONNECTION_IDS=...
```

### G2. Шум от Telegram reactions

Симптом: в некоторых чатах Telegram API возвращал ошибку на `setMessageReaction`.

Решение: реакции выключены по умолчанию и включаются только явным флагом:

```bash
TG_AGENT_REACTIONS_ENABLED=1
```

### G2. Preview проверял не тот сценарий дашборда

Симптом: `preview "Дай выручку за вчера"` мог показывать диагностический data-gap вместо ответа по выручке.

Причина: CLI preview определял intent, но не передавал исходный текст в dashboard handler.

Решение: `DASHBOARD-QA` и `DASHBOARD-CHART` теперь проходят через обычный обработчик текстовой команды.

## Остается внешним условием

### G0. Runtime зависит от локального компьютера

Сейчас бот работает как локальный процесс. Если компьютер выключен или сеть пропала, бот недоступен.

Решение: перенос на постоянный сервер.

### G1. Секреты и live-env

Для живого бота нужны реальные значения `.env`: Telegram token, ClickUp token, OpenAI key, dashboard paths.

Правило: секреты не хранить в публичном GitHub.

### G2. Голосовые ответы высокого качества

Код поддерживает OpenAI TTS, но нужен `OPENAI_API_KEY`.

Без ключа голосовая озвучка высокого качества не заработает.

### G2. Google Sheets sync

Если нужен внешний журнал поручений, нужно заполнить:

```bash
TG_AGENT_SHEETS_WEBHOOK_URL=...
TG_AGENT_SHEETS_SECRET=...
```

Без этого журнал хранится локально в `data/*.jsonl`.
