# Команды бота

## Базовые

- `/start` — короткое описание возможностей.
- `/help` — список команд.
- `/whoami` — показать `chat_id`, `user_id`, username и имя для настройки доступа.
- `/health` — проверить подключение, файлы и источники.
- `/doctor` — диагностика готовности к запуску.
- `/self_test` — локальная самопроверка логики.

## Память и задачи

- `задача ...` — сохранить поручение.
- `вопрос ...` — сохранить вопрос.
- `решение ...` — сохранить решение.
- `риск ...` или `блокер ...` — сохранить риск.
- `что известно про ...` — найти контекст.
- `что решили по ...` — найти решения по теме.
- `задачи по мне` — показать задачи пользователя, если настроена связка Telegram ID и ClickUp ID.

## Дашборд

- `какая выручка за вчера`
- `какая выручка по e-commerce за неделю`
- `какое направление отстаёт от плана`
- `покажи диаграмму по направлениям за вчера`

Бот должен возвращать период, источник, ссылку на страницу дашборда и предупреждение, если данные старые.

## Группы

- `/groups` — показать известные группы.
- `/send_group <группа или chat_id> | <текст>` — отправить сообщение в группу.
- `/schedule_group <группа или chat_id> | каждый день в 10:00 | <текст>` — поставить регулярный запрос или напоминание.
- `/reminders` — список напоминаний.
- `/cancel_reminder <id>` — отменить напоминание.

## Сообщения для команды

Команда:

```text
собери сообщение для коллег
ресурс: ...
ссылка: ...
логин: ...
пароль: ...
для чего: ...
```

Бот вернёт готовый человеческий текст для рассылки.
