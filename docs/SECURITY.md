# Безопасность

## Что нельзя коммитить

- `.env`;
- токены Telegram и ClickUp;
- пароли и логины;
- историю чатов;
- реальные клиентские выгрузки;
- логи с персональными данными;
- файлы `deployment-access`.

## Доступ к боту

Бот работает только для разрешённых `user_id` и `chat_id`.

Публичные команды до добавления доступа:

- `/start`
- `/help`
- `/whoami`

Этого достаточно, чтобы новый пользователь прислал свой ID администратору.

## Передача живого бота

Код передаётся через GitHub. Секреты передаются отдельно. Если два сервера одновременно запустят одного Telegram-бота с одним токеном в режиме polling, Telegram начнёт отдавать обновления только одному процессу, а второй будет конфликтовать. Поэтому при переносе живого бота старый процесс надо остановить после проверки нового запуска.
