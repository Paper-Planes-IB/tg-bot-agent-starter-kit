# Эксплуатация

## Ежедневная проверка

В Telegram:

```text
/health
/doctor
сводка за день
какая выручка за вчера
задачи по мне
```

После добавления бота в новые группы проверить, что в неразрешённых группах он молчит, а в разрешённых отвечает только на команды и обращения.

После подключения Telegram Business проверить:

```text
сводка по личным чатам
```

Если сводка пустая, посмотреть `data/tg_agent_logs/` и добавить новый `business_connection_id` в `TG_AGENT_ALLOWED_BUSINESS_CONNECTION_IDS`.

## Логи

Логи пишутся в:

```text
data/tg_agent_logs/
```

История сообщений и память пишутся в JSONL-файлы внутри `data/`. Эти файлы не должны попадать в GitHub.

## Обновление кода

1. Остановить фоновый процесс.
2. Обновить код.
3. Запустить `self-test`.
4. Запустить `doctor`.
5. Запустить бота.
6. Проверить в Telegram `/health`.

## Перенос на другой сервер

1. Склонировать репозиторий.
2. Передать `.env` защищённым способом.
3. Скопировать нужные локальные данные: `data/dashboard`, рабочие справочники, если они нужны.
4. Проверить `telegram-check`.
5. Остановить старый live-процесс.
6. Запустить новый live-процесс.
